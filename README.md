# UnleashWP Code Examples, Vol. 1

Every code example from the book **UnleashWP Vol. 1**, ready to test, adapt and extend. The book is for developers, agencies and teams who want to run WordPress in a modern, professional way. More about it at [unleash-wp.com](https://www.unleash-wp.com).

## Finding an example

The book numbers each example as chapter and position. The files follow the same numbers:

```
volume-1/<chapter>/<position>.<ext>
```

Example 3-2 in the book (chapter 3, second example) is `volume-1/03/2.*`. Chapter 1 is the exception: its two files are named `config.yaml` and `setup.sh`.

The examples cover Docker, DDEV, WP-CLI, Node.js with npm, and Composer, plus the PHP, YAML, JSON and XML configuration that goes with them.

## Requirements

Depending on the chapter: Docker, DDEV, WP-CLI, Node.js with npm, and Composer, plus the permissions the example needs (file system, execution, database).

## Using the examples

1. Follow the chapters in the book; each example assumes the steps before it.
2. Run them in a development environment only, never directly on a production site.
3. Adapt them to your project. Use in your own and in commercial projects is allowed.

## Found a bug?

Open an issue with the bug form, or better, fix it and open a pull request. Keep to the style of the existing examples: clean, minimal, practical, with the licence header at the top of each file. Details in [CONTRIBUTING.md](CONTRIBUTING.md).

There is no individual support for fitting the examples into your own project.
